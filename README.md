# Harper & Ellie Mae — Christmas Movie Website

A premium Christmas landing page for GitHub Pages.

## Features
- Four-corner premium entrance animation
- Real photographic Christmas imagery from Pexels
- Live countdown to December 25
- Automatic Christmas hamper slideshow
- Multiple Santa's-helper/elf scenes
- Large Santa flight sequence that starts off-screen, travels diagonally/down the page and exits
- Santa speech bubble: “HO HO HO!”
- Browser speech synthesis reads a personalised Santa message
- “Make Santa fly again” button
- Animated Christmas train with helpers, presents, treats and toys
- Personal Santa letter for Harper & Ellie Mae
- Responsive mobile layout
- Reduced-motion accessibility support
- No build step

## GitHub Pages
Upload all files to the root of a repository and enable Settings → Pages → Deploy from branch → main → /(root).

## Sound
Browsers block automatic audio/speech in many circumstances. The page therefore includes a “Christmas sound” button. Press it once to hear Santa's message. The Santa flight also has its visual “HO HO HO!” bubble.

## Photography
The page references Pexels-hosted photographs so it stays lightweight. If you want the site to be completely self-contained/offline, download appropriately licensed images and place them in an `assets` folder, then replace the image URLs in `index.html`.
